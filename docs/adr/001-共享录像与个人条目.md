# ADR 001 · 共享录像与个人条目

状态：已采纳

日期：2026-11-25

5E 比赛编号定位同一份下载和解析结果。账号在本机 SQLite 中持有独立的录像条目，同一个账号对同一份录像只有一个条目。接口根据会话解析条目归属，再读取磁盘上的录像和分析结果。

选手绑定属于个人条目，账号另保存后续导入使用的常用 Steam ID。导出任务在创建时保存账号、条目编号、文件名和地图。移除个人条目后，其他账号仍可访问共享录像，提交者仍可从导出历史下载。

原始录像、解析文件、任务和 MP4 继续放在磁盘。旧条目以原录像编号登记到首个管理员，旧任务通过 SQLite 的归属索引开放给该管理员。运行期间使用同一个服务进程和录制队列。
