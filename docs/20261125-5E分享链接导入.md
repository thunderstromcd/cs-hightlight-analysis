# 5E 分享链接导入

状态：已完成

## 需求

首页粘贴 5E 比赛分享链接或完整分享文案，从 URL 的 `matchcode` 提取对局 ID。仅支持 5E，不接入完美平台，不要求 5E 账号登录。

## 流程

`分享链接 → 5E 比赛详情 → demo_url → 下载 ZIP → 解压 .dem → 现有分析模块 → 高光页面`

- 新增 `POST /api/demos/import`，请求体 `{ "link": "分享链接或分享文案" }`。
- 创建录像后立即返回，下载和解压在本机后台执行；比赛详情页和录像库继续使用现有轮询接口。
- 新增 `downloading`、`extracting` 状态，下载进度以实际接收字节计算。
- 按 `importedFrom.platform + importedFrom.matchId` 复用记录，同时提交同一比赛也只创建一条。
- 导入失败后再次提交原链接重试；进程重启后访问录像库或详情页重新下载尚未完成的导入。
- 下载文件和解压文件均限制 1 GB；使用 yauzl 从磁盘读取 ZIP，只将 `.dem` 解压至系统生成的目标文件，避免将整场录像加载进内存。
- 解压完成后复用 `startAnalysis`，文件名带 `5eplay`，保留现有来源识别逻辑。
- 下载地址仅接受 5E CDN 的 HTTPS 地址，不请求用户粘贴的页面地址。
