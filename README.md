# 拆片

在自己的电脑上打开的一个网页：上传 Counter-Strike 的 `.dem` 或粘贴 5E 比赛分享链接，看全场每个人的高光，勾选要留的片段。成片是一条 MP4，由这台 Windows 上的 CS2 客户端录出来。打开网页的人什么都不用装。

解析用 [`@akiver/cs-demo-analyzer`](https://github.com/akiver/cs-demo-analyzer)，不依赖 CS Demo Manager。导出才调用官方命令行 `csdm video`。这里没有把 Electron 版 CS Demo Manager 套进网页，也没有 2D 合成，也没有 5E / 完美世界账号登录。

## 一条命令

需要 Node.js 20 或更新。

```bash
npm install
npm run build
npm start
```

浏览器打开 [http://127.0.0.1:38471](http://127.0.0.1:38471)。服务听在 `0.0.0.0:38471`。`npm start` 走生产模式（`next start`），不会出现左下角的 Next.js「N」指示器。开发时用 `npm run dev`，配置里已关掉该指示器。

高光规则的测试：

```bash
npm test
```

## 现在能做什么

1. 上传 GOTV 的 `.dem`（CS2 或 CS:GO，最大 1 GB）。
2. 本机解析出击杀、残局、拆包。
3. 按选手查看高光，勾选要留的片段。勾选记在这个浏览器里。
4. 请求导出。没有 `csdm` 时，页面会明确提示「录像机未就绪」，解析和勾选不受影响。

录像、解析结果和导出任务写在 `data/`，不进 git。

首页「从 5E 导入」可粘贴完整比赛分享文案，系统从链接的 `matchcode` 获取对局 ID，后台下载、解压并自动分析，无需登录 5E。同场比赛重复导入复用已有记录；失败后可在比赛页「重新导入」。平台尚未生成或已过期的录像无法导入。仅支持 5E，不接入完美平台。详见 [5E 分享链接导入](docs/20261125-5E分享链接导入.md)。

## 高光门槛

规则对着分析器的真实 JSON 写的：`kills`、`clutches`、`bombsDefused`、`rounds`、`tickrate`。SteamID64 在 JSON 里是超过安全整数的数字，读入时先改成字符串。

会计入击杀的，是敌方、非自杀、不是 C4 或世界伤害的那一枪。

- **五杀 / 四杀 / 三杀**：同一选手在同一回合的击杀数。
- **双杀**：恰好两杀，而且第一枪到最后一枪不超过 6 秒。拖得更久的两杀不单列。
- **一枪多杀**：同一 tick 击倒至少两人。
- **残局**：分析器标记的 `clutches` 里，`hasWon` 且 `opponentCount >= 2`。打赢的 1v1 太常见，不列。片段从残局开始收到回合结束，最长大约 75 秒，保住的是结尾。
- **刀杀、不开镜、电击枪、投掷物、盲打、穿烟、穿墙、空中爆头**：单独一枪，而且这枪没有已经算进上面的多杀片段。多杀片段会带上这些标签。
- **忍者拆包**：拆包时还有匪徒活着。如果这个人同一回合已经有打赢的残局，就标在那条残局上。

时间按这场的 `tickrate` 换算，分析器没给就按 64。片段不会伸进冻结时间，也不会超过回合结束。

## 导出

预设写死，页面上不能改：

- 1280×720
- 30 帧
- 只保留击杀提示（`showOnlyDeathNotices`）
- 一次只跑一条
- 勾选的片段按比赛时间接成一条 MP4

有 `csdm` 时，队列会先 `csdm analyze`（官方命令要求录像在它自己的库里），再 `csdm video --config-file`。录像系统用 CS 客户端，编码用 FFmpeg，容器是 mp4，录完关掉游戏。`csdm` 的查找顺序：环境变量 `CSDM_PATH`，然后是 `PATH`，Windows 上再看 `%LOCALAPPDATA%\Programs\CS Demo Manager\csdm.exe`。

这个项目不会安装 `csdm` 或 CS2，也不会改路由器。

可选环境变量 `ACCESS_TOKEN`。设了之后，网页要先填这串口令。准备把服务暴露出去时建议打开。

## 给别人看

这台电脑在两层局域网 NAT 后面，运营商还有一层 NAT，公网端口转发行不通。1.0 对外用 OpenFrp（免费档大约 12 Mbps）：大陆节点要实名，大陆节点的 HTTP/HTTPS 还要已备案域名，所以先用节点主机名加端口，或 Natayark 的免费域名 `*.off.gs`。说明在 [docs/部署说明.md](docs/部署说明.md)。
